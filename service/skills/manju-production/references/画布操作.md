# 画布操作

本文件约定剧本、整片质感、资产和分段视频提示词在画布上的组织方式。平台工具参数以平台为准；只写工具名和要完成的动作，不假设未提供的参数。

## 节点结构与命名

按下列关系组织节点：

- 剧本节点（主） →「整片质感」文字节点 → 资产分组与各段分组。
- 「资产」分组中，每个人物、场景、关键道具各有一个参考图提示词节点和对应的生成图；同一人物的不同年龄或稳定状态用自然名称清楚区分。
- 每段一个分组，以段落名命名；分组内放该段分镜节点、完整视频提示词节点和生成的视频。

节点标题直接使用人物、场景、道具或段落名称，便于查找与返修，例如「叶惊澜」「叶家小屋」「旧铜铃」「山门对峙」「山门对峙-分镜」「山门对峙-视频提示词」。整片质感节点标题为「整片质感」。同名人物的不同年龄或状态使用自然名称，例如「少年叶惊澜」。

## 建立与连接

- 查找已有剧本时使用 `get_selected_nodes`、`get_canvas_summary`；需要进一步读取节点或关系时用 `query_canvas_nodes`、`get_node`、`get_upstream_nodes`、`get_downstream_nodes`、`get_connected_nodes`。
- 用户粘贴的新剧本用 `create_primary_script_node` 建立主剧本节点。
- 用 `create_text_node` 建立整片质感、资产提示词、分镜和视频提示词节点；修改文字用 `update_text_node`。需要改其他节点信息时用 `update_node`。
- 用 `create_group` 建立「资产」分组及各段分组；用 `arrange_nodes` 整理节点布局。删除节点或连线前确认其不再被后续内容引用，并分别使用 `delete_node` 或 `delete_connection`。
- 用 `create_connection` 建立这些关系：剧本 → 各段分组；整片质感 → 各段视频提示词；资产参考图 → 实际使用该资产的段视频提示词。必要时也把段分镜节点连入本段视频提示词关系。
- 用户上传并 @ 引用本段需要的资产；将对应资产参考图节点连到实际使用它的段视频提示词节点。视频提示词节点正文只放五栏目提示词，不附加资产介绍行。
- 视频提示词节点标题可在段落名后添加推荐时长后缀；也可将时长填入生成时长设置。节点正文只放可复制的提示词，不放段后推荐时长句。
- 资产提示词节点写入对应人物、场景或关键道具的完整中文提示词。每项都要建节点，已有有效参考图时可在节点中记录沿用关系。

## 生成前确认与进度

参考图和视频提示词及节点全部完成后，进入⑨生成。每次准备调用 `generate_image` 或 `generate_video` 前，先向用户列出本次生成清单、数量和将使用的模型，停下等用户确认。清单或提示词有变化时，重新列出变化后的内容并确认。用户确认后再调用对应生成工具；不要把确认扩展到清单外的项目。

- ④只完成资产清单、参考图提示词节点和资产分组，不调用 `generate_image`。
- ⑨先列出即将生成的人物、场景和道具图像数量、名称和模型；停下等确认，再按清单逐项调用 `generate_image` 并将结果连到实际使用它的视频提示词。
- 参考图生成完成后，再列出即将生成的视频段数、段落名称和模型；停下等确认，再按清单调用 `generate_video`，并引用该段实际使用的参考图。
- 用户说“先不生成”或“暂不生成”时只跳过⑨媒体生成，照常完成并交付文字制作及画布节点。
- 用 `get_media_task_status` 或 `get_generation_task` 查询已提交生成任务的状态。
- 用 `get_generation_config` 查询当前模型配置；模型可用选项或参数以平台返回为准。
- 调用 `generate_image` 生成参考图时，画布节点尺寸须与提示词中的图片比例一致；人物四视图按固定模板原文生成，竖版 9:16 只设在画布节点尺寸中。

## 中断续做

用 `set_agent_state` 记录已锁定的画幅、视频模型和整片质感，当前进行到哪一步，以及哪些段已生成。恢复时先通过画布读取工具核对记录与实际节点状态；若记录与画布不一致，以当前画布核对后再继续，必要时询问用户。
