# 整片质感

## 用途与输入

根据用户提供的剧本、剧情或场景视觉信息，建立整片统一的视觉质感与色调。整片质感在全片只确定一次，供所有分段沿用；不要按段重设画风。输入可直接使用已有剧本或画布上的相关视觉信息。

## 生成步骤

1. 判断视觉表现类型、年代、地域等影响视觉风格的信息；情绪判断只供内部选择视觉参数。只提取影响全片视觉基底的信息，不把具体昼夜光线放进整片质感。
2. 阅读《整片质感-资料库.md》，从实际列出的八类资料中每类各选 1–3 项与项目相符的视觉参数。优先形成一套连贯基底，避免选择彼此冲突的参数。
3. 将选择整理为一段连贯、可直接复制的中文视觉提示词。可以先在工作过程中简要说明选择依据，最终成品只保留视觉描述，不写剧情、事件、人物行动或分析过程。
4. 将完整成品写入画布上「整片质感」节点，作为全片唯一的质感锁定；后续每段视频提示词都完整复制其中同一段基底原文，文字保持完全一致，然后补写该段画面里实际出现的人物、场景和物件的材质质感。不得用“统一质感”等引用代替基底。本段不存在的物件或场景，即使其他段出现，也不写入本段材质描述。

全片基底只写贯穿全片的介质、色调倾向、反差、颗粒、镜头观感和风格，不写只在部分段落出现的物件及其专属颜色或材质。例如，嫁衣的大红只写进有嫁衣的段落，不写成全片的“大红强调”。

## 成品结构

以自然语言依次覆盖以下八项，可用逗号或分句衔接：

1. 拍摄介质或成像载体
2. 色调体系
3. 对比度与灰度
4. 颗粒与纹理
5. 镜头观感
6. 年代感或视觉风格

只写可见的视觉效果，使用中文；成品不复述剧情或场景事件，不写具体昼夜光线。各项按实际需要具体描述，不适用的项目不强行添加。整片质感确定后，各段局部光影不得另起一套色调。
