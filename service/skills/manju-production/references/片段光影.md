处理每段视频提示词的「补充光影」时阅读；资料库 A–F 仅供挑选时参考，不作为输出结构。

# 片段光影

## 用途与输入

在整片质感已经锁定的基础上，为当前分段设计局部光影。输入为已锁定的整片质感、该段画面信息与情绪锚点。整片介质和色调保持不变，各段只调整有画面依据的局部光影。

## 生成步骤

1. 判断当前段落的情绪锚点及变化方向：进入、递进、转折、爆发、停顿、释放或余韵；平静段落的光影可基本不变。
2. 从资料库 A–F 挑选适合的光影参数，仅用于思考，不按六项逐项输出。
3. 为每项光影描述找到画面中的依据，例如场景已有的自然光、灯具、屏幕、发光道具、遮挡、开合或环境介质。平静段落即使光影基本不变，大气介质也要轻微变化，且必须有画面依据，例如场景里已有的尘、雾、烟或雨。光源只影响合理范围并随距离衰减；没有依据时保持稳定，不凭空增加光源、闪烁、变色、雾、烟或粒子。
4. 输出 1–2 句中文视觉描述，不超过 60 字：说明主光从哪里来及明暗冷暖；有情绪转折时加一句光影变化。光源须有画面依据。
5. 将成品放入该段视频提示词的「补充光影」部分，并沿用整片质感节点的锁定内容。

## 输出格式

【补充光影】（1–2 句，不超过 60 字）

原六项仅作挑选时的思考清单，不输出六个小标题。

## 资料库 A–F

以下条目供选择参数时参考：

【资料库 A】情绪节奏类型（先选定本段属于哪种）
============================================================

—— 叙事功能型 ——
- Opening Establishing 开场建立：稳定、信息呈现 → 平光、慢揭示
- Rising Tension 紧张递进：逐渐压迫 → 阴影逐渐加深、光源减少
- Sudden Shift 突然转折：情绪反转 → 光骤变、色温跳变
- Climax Peak 高潮顶点：情绪爆发 → 强对比、剧烈光影
- Quiet Pause 安静停顿：呼吸时刻 → 柔和均匀光、最少变化
- Emotional Release 情感释放：哭泣/拥抱/顿悟 → 柔光包裹、暖意涌入
- Revelation Moment 揭示瞬间：真相浮现 → 光从黑暗中出现、单点光
- Falling Resolution 下降收束：余韵 → 光线柔化、色温降温
- Memory Flashback 回忆闪回：进入过去 → 高光过曝、漏光、柔焦
- Dream Drift 梦境漂移：脱离现实 → 弥散光、雾化、不可能光源
- Foreshadowing 不祥预兆：埋下危险 → 阴影侵入、冷色侵蚀
- Catharsis Aftermath 宣泄余烬：事件后的死寂 → 单一冷光源、长阴影

—— 心理状态型 ——
- Inner Peace 内心平静：均匀柔光、自然色温
- Anxiety Building 焦虑积累：闪烁、不稳定、绿色调侵入
- Despair Sinking 绝望下沉：光从顶部压下、底部全黑
- Hope Emerging 希望浮现：远处出现光点、暖光渐入
- Anger Burning 愤怒燃烧：红色光侵入、硬光顶光
- Love Blooming 爱意绽放：柔焦逆光、金色边缘光
- Fear Creeping 恐惧蔓延：阴影从边缘侵入、光源减弱
- Confusion Disorienting 困惑迷失：多光源冲突、色温混乱
- Determination Hardening 决心坚定：硬光侧打、轮廓清晰
- Loneliness Echoing 孤独回响：单一冷光源、巨大空旷阴影
- Nostalgia Drifting 怀旧飘移：过曝高光、暖黄漏光
- Madness Spiraling 疯狂螺旋：旋转光、闪烁、色彩扭曲
