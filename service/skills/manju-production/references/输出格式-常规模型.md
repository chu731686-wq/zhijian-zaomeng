本文件在视频模型判定为常规模型后读取，按用户选择输出模式一、模式二或双模式。每段独立视频提示词严格按以下顺序写五个栏目：

【精准主体】【整片质感】【核心剧情】【补充光影】【防崩约束】

# 通用字符规范

台词用中文引号，写成「角色说：“台词”」，例如：林小满说：“知道了。”；画外音写「娘（画外）说：“台词”」；小语种注明语种。音效用尖括号，例如：<远处传来狗叫声>。音乐用圆括号，例如：（背景中播放着舒缓的钢琴曲）。**每句台词只写一次**，不用花括号，也不在同一镜头里重复写。

# 模式一：逐镜头分镜

在【核心剧情】下直接按剧情顺序写镜头1、镜头2……。每镜依次写拍摄、主体动作与表情、位置或空间变化、台词、音乐/音效。拍摄融合对应画幅的景别、构图、视角和运镜偏好。动作写清肢体部位、幅度、速度、力度、神态变化及前后动作承接；镜间逻辑通顺。

常规模型逐镜不写秒数。只输出提示词正文，不附加解释。

全片基底只保留贯穿全片的视觉参数；局部物件及其专属颜色、材质只写在实际出现的段落里。例如，嫁衣的大红不进入全片基底，只补在有嫁衣的段落。

```text
【精准主体】
人物姓名与本段外观、妆容、服装、固定配饰、固定道具及当前状态；场景地点、时间（日/夜）和内外须照剧本场头原样写，不改成黄昏、傍晚等；光影须与场头时间一致。另写天气、空间结构、初始站位、关键道具位置、运动轴线、主光方向和环境声音。只写本段需要的信息。若小变化在本段内发生，写明起始状态及变化发生的镜头和变化后状态；不得写“全程维持”等与镜头变化矛盾的描述。

【整片质感】
完整复制全片质感节点中的同一段基底原文，逐段保持完全一致；再写本段画面里实际出现的人物、场景和物件的材质质感。不得用“统一质感”等引用代替基底，不写本段不存在的内容。

【核心剧情】
镜头1：
拍摄：……
主体动作与表情：……
位置或空间变化：……
台词：角色说：“……”
音乐/音效：（……）<……>

镜头2：
……

镜头标题写作“镜头1：……”并只写镜头内容，不附秒数或“约X秒”；逐镜时长估算只用于段落规划，不写进【核心剧情】。

【补充光影】本段 1–2 句、不超过 60 字，说明有画面依据的主光来源、明暗冷暖；有情绪转折时写光影变化。

【防崩约束】按锁定画幅复制对应原文：横版用横版输出模块原文；竖版用竖版输出模块原文。两版原文均为：人物面部和身体比例稳定不变形，动作连贯自然，不僵硬，无穿模无卡顿，同场景内背景陈设、家具位置、方位全程不变，“保持无字幕”、“避免生成任何文字或字幕”，“不要生成Logo”，“不要生成水印”，视频全程禁止出现外形、着装、配饰完全一致的人物，禁止生成同款分身、双胞胎效果。
```

# 模式二：综合描述

在【核心剧情】下写一段可直接投喂的综合描述，按剧情顺序涵盖人物、动作、场景、摄影、声音和连续性，不新增剧情，不写互相冲突的摄影指令。

```text
【精准主体】本段人物与场景的必要识别信息及连续性锚点；时间（日/夜）和内外照剧本场头原样写，不改成黄昏、傍晚等，光影与场头时间一致。若小变化在本段内发生，写明起始状态及变化发生的镜头和变化后状态；不得写“全程维持”等与镜头变化矛盾的描述。
【整片质感】完整复制全片质感节点中的同一段基底原文，逐段保持完全一致；再写本段实际出现内容的材质质感，不用“统一质感”等引用代替基底。
【核心剧情】综合描述……
【补充光影】……
【防崩约束】按锁定画幅复制对应的横版或竖版约束原文（见模式一）。
```

视频提示词写完后，在提示词正文之外另起一句：`推荐时长：约 X 秒`。该句不放进提示词复制内容。常规模型逐镜不写秒数；按模型实际时长范围估算整段推荐时长。

默认模式一；只有用户明确要求模式二或双模式才切换。双模式分别输出完整提示词，各自附一条段后推荐时长。
