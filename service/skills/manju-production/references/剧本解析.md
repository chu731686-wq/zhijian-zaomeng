# 剧本解析与覆盖

解析已有剧本，不把编剧格式偏好当作删改原文的理由。本步骤用于把原文整理成后续资产、分段和分镜可追溯的制作依据；不改写剧情。

| 原文标记 | 解析方式 | 制作去向 |
|---|---|---|
| 集、场、昼夜、内外、地点、主要人物 | 记录原有场序、时空与出场人物 | 场景、人物、空间与光源条件 |
| △场景或动作 | 作为原始可视内容来源；多个动作可按叙事拆开 | 分段覆盖与分镜动作 |
| 人物（动作/情绪）：台词 | 分开记录可见动作、表演要求、说话文字 | 画面表演与原对白 |
| 内心 OS、旁白 VO | 按原文标明画外声音，不强制人物张嘴 | 对应声音与画面承载；不新增旁白 |
| 闪回标记 | 保留叙事顺序，记录进入/退出及时间身份 | 人物年龄状态、场景与资产版本 |
| 字幕、身份说明等指定文字 | 保留原文内容与出现时点；默认作为后期文字需求 | 文字清单，不要求模型额外生成文字 |
| 信件、报告、铭文等剧情文字 | 保留理解剧情所需内容及可见时点 | 关键道具、必要特写与后期文字 |

角色首次或再次出场的身份说明属于输入信息；不得自行给所有人物新增身份字幕。缺少场序或动作标记时，按语义解析，不先要求用户重排全文。台词原样保留，标点、语序、称谓不得为适配镜头而改动；需要拆分承载时保持文字顺序，不重复或遗漏。

通读用户选定的范围后建立以下记录：

1. **原文节点**：按原文顺序记录来源场序或段落位置、事件/动作、环境变化及原对白。
2. **资产候选**：人物、场景、关键道具；注明原文明确的信息、已有锁定信息与待制作设计的信息。
3. **情绪与节奏**：记录主情绪及诱因、转折/揭露/停顿位置；不以“更爽”或补足时长为由改变剧情。
4. **覆盖关系**：原文节点 → 片段候选 → 镜号 → 视频提示词。一个原文节点可由多镜承载，但不得漏掉事件或重复播放对白。
5. **连续性风险**：标出多人站位、手部互动、长对白、换装/年龄、时间跳转、文字线索、光源变化、道具持有与稳定状态变化。

剧情边界按以下规则处理：只补视线、走位、停顿、环境或道具承接等过渡动作；不得新增事件、人物、线索或结果。原文存在涉及人物身份、事件因果、关键线索或结果的矛盾时，暂停受影响部分并向用户集中询问。不得用制作设计替原剧情补因果。次要背景细节确需设计时，标明这是制作设计，不伪装成原文事实。

完成解析后将覆盖关系用于分段和质量门检查；用户只要求某一步时，仅处理该范围，并继承画布中已有且有效的剧本与锁定信息。
