# 质量门与返修

最终版交付前按阶段检查并先修复再推进。已通过的上游不重复生成；上游锚点改变时更新受影响的下游节点。遇到原文缺口或需要用户决定的矛盾，标明具体缺口并暂停受影响部分，不无限重试，也不伪装通过。

## 阶段检查

| 阶段 | 必查 | 失败示例 |
|---|---|---|
| 剧本解析 | 所选范围通读；原文顺序、事件、台词、闪回和剧情文字保留；只补允许的过渡动作 | 漏读尾场、改台词、新增人物/线索/结果 |
| 项目锁定 | 处理范围、横竖画幅、视频模型、表现类型已明确；用户已说明画幅时直接锁定，未说明或拿不准时先按剧本推荐并给出一句理由、停下确认；其余缺失信息一次问齐 | 未锁定画幅就选构图；把查不到的模型套入 Seedance 2.5 路线 |
| 整片质感 | 全片只定一次，包含介质、色调、对比、颗粒、镜头观感和风格；不写具体昼夜光线；每段完整复制同一段全片基底原文，再写本段实际出现内容的材质质感 | 各段另定基底、只写“统一质感”等引用，或写入本段不存在的物件或场景质感；例如嫁衣大红只写进有嫁衣的段落，不进入全片基底 |
| 资产与参考图 | 人物、场景、道具直接以名字和稳定状态记录；每项有参考图提示词与画布节点；小幅发型/状态变化写在【精准主体】，若小变化在本段内发生，写明起始状态及变化发生的镜头和变化后状态，不得写“全程维持”等与镜头变化矛盾的描述；明显换装等大变化新增状态资产，出图时上传该人物原定妆图作为参考图，提示词写“与参考图为同一人物，保持面容与身形，改为……”且不写人名；⑨生成前列清单并等确认 | 名称或状态混淆、场景反打布局漂移、确认前生成图像、大变化未建新资产或漏用原定妆参考图；例如嫁衣资产写“与参考图为同一人物，保持面容与身形，改为穿着深红嫁衣”，不带人名 |
| 分段规划 | 一次生成对应一段；按模型实际上下限规划；查不到时 Seedance 2.5 每段 4–30 秒，其余模型（包括查不到名称的模型）走常规模型路线、每段 4–15 秒；逐段估算时长＝全部台词字数÷4（秒）＋每个主要动作约 1–2 秒；超过上限就在两句台词之间再拆；不足下限的段仅并入同场景、着装状态相同的相邻段；剧本换场（新场次，即使地点相同、只隔“片刻后”）和人物明显换装（需新参考图）必须另起一段，每段里每个人物只有一种着装状态；原文覆盖且出入点可接 | 未估算时长、超出上限、低于下限、合并换场或换装、段内人物换装、在台词或动作中间切开、漏事件、靠新增内容遮挡转场 |
| 分镜与连续性 | 按路线选对逐镜时长规则；横版以中景/近景为主，竖版以近景/特写为主且主体纵向居中、避免大幅横摇；景别比例仅作倾向；台词原样；轴线、视线、方向、速度、站位、持物与资产锚点连续 | 常规模型【核心剧情】镜头标题写“镜头1：……”且不附秒数或“约X秒”；Seedance 2.5 无建议时长、Seedance 2.5 一镜里既说整句台词又做大动作（拍桌、扑救、出拳等，应拆成两镜）、同镜塞多次切镜、人物左右突变 |
| 光影 | 每段有 1–2 句、不超过 60 字的光影补充，说明主光来源、明暗冷暖；有情绪转折时加一句光影变化，光源有画面依据 | 光源无依据、关键动作不可读 |
| 视频提示词 | 每段可单独投喂；依次只有【精准主体】【整片质感】【核心剧情】【补充光影】【防崩约束】；Seedance 2.5 场景连续性锚点合并在【精准主体】；提示词之后另起一句推荐时长，不混入复制内容；无“同上” | 栏目缺失、次序错误、资产介绍行混入提示词、缺少本段识别信息或防崩约束 |
| 文字与声音 | 原台词保留且每句只出现一次；台词统一写成「角色说：“台词”」，不用花括号；剧情必需文字保留并标“可后期合成”；无无依据的额外文字或音效 | 台词删改、随机字幕/文字、音效没有动作或环境来源 |
| 画布结构 | 节点标题直接使用名字；按段落分组；资产参考图和整片质感连到对应视频提示词；剧本连到各段 | 节点难以查找、参考图连错段、提示词脱离剧本 |
| 生成确认 | 每次图像或视频生成前列出数量/内容与模型，并停下等用户确认；生成后查询进度 | 未确认就调用生成；生成任务状态未跟进 |

⑤分段和⑥分镜完成后逐段自检：段时长须在当前模型实际上下限内；Seedance 2.5 各镜建议时长之和不得超过段上限，每镜台词正文中文字数不得超过镜长×4；常规模型不写逐镜秒数，也按每秒不超过 4 个中文字估算对白承载。超出上限时拆段或延长镜头，低于下限时并入相邻段并重新核对，不压缩台词。

视频提示词完成后自查：台词用「角色说：“台词”」（两条路线一样），音效用 <尖括号>，音乐用（圆括号）；竖版开头不先放全景。推荐时长句不放入视频提示词节点正文；图片提示词不写推荐时长。

逐段画幅自查：每段视频提示词内出现的“横版/竖版”及“16:9/9:16”字样，必须与②锁定的画幅一致；出现互相矛盾或与锁定画幅不符的描述时先修正再交付。

对白承载按约每秒 3–4 个中文字估算，哭腔、停顿等留出更多时间；估算用于镜头组织，不得因此改写台词。画幅检查面向正片及剧情关键帧，不误判纯白背景等非正片参考图。没有实际生成视频时，只能声明文本与画布结构检查完成，不能承诺成片不会换脸、穿模或出现文字错误。

## 终交付审查与返修

用覆盖关系逐项对照原文、分镜和视频提示词，确认没有漏事件、重复台词或提前揭露；检查资产、道具、场景、光源状态跨段连续；确认主文件共享约束的各项要求均满足。只针对本次处理范围声明完成。

全流程或指定步骤交付时报告 `通过 / 待确认 / 需返修`，给出少量具体证据。上游资产或锚点变化时，只返修受影响的下游；原文矛盾或缺失需要用户决策时明确标出，不自行填补。

图片提示词自查：人物定妆、四视图提示词正文不出现人名或“与某某交手的”“同一女子某某”等带名字的说法；关系用外貌或身份描述；四视图与《资产与参考图.md》里的固定模板逐字一致。

参考图比例自查：图片提示词比例与视频模型无关；人物定妆正文写竖版 9:16、人物四视图只在画布节点尺寸设竖版 9:16、场景（含四宫格整图）按②锁定画幅、道具按形状默认横版 16:9且细高物件用竖版 9:16，`generate_image` 尺寸与对应比例一致。

【精准主体】自查：时间（日/夜）和内外照剧本场头原样写，不改成黄昏、傍晚等；光影与场头时间一致。
