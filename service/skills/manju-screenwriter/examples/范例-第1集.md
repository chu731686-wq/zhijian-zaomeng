# 范例：第 1 集（原创，总监写）

什么时候读：写第 1 集、写任何一集前想对一下格式和手感时。人名、设定均为原创示范，**不要在用户的项目里复用**。

剧名：《我替天道记账》｜女频·玄幻大女主｜AI 漫剧·动态漫｜单集约 1.5 分钟
一句话卖点：被夺走灵根、推下悬崖的杂役弟子，捡到一本天道账本——谁欠她的，连本带利都得还。

---

```
第1集
场1-1日/外 青云宗·断崖 主要人物：沈禾、白芷柔、严崇
△狂风卷着碎石滚进深渊，崖下云海翻涌。
△沈禾被两名执法弟子按跪在崖边，半个身子探出悬崖。
△【字幕：沈禾，青云宗杂役弟子】
严崇（举起一枚碎裂的玉佩）：偷盗宗门圣物，按律，废去修为，逐出山门。
沈禾：不是我！是她放进我包袱的！
△白芷柔捂住心口，眼眶一红。
△【字幕：白芷柔，宗主亲传弟子】
白芷柔（哽咽）：师妹，我待你如亲妹妹……
△围观弟子一片哗然。
众弟子：杂役也敢攀咬亲传？
△白芷柔快步上前，像是要扶沈禾起身，俯在她耳边。
白芷柔（压低声音）：你的灵根，我用得很顺手。
△沈禾瞳孔一缩。
沈禾内心os：三年前那场走火入魔……是她！
△白芷柔扶着沈禾的手腕轻轻一松，指尖一推。
△沈禾向后仰倒，坠入云海。
白芷柔（惊叫）：师妹——！

场1-2夜/外 断崖底·寒潭 主要人物：沈禾
△寒潭边，沈禾趴在乱石上，浑身湿透，指甲抠进泥里。
△一本泛着金光的旧账本从潭底缓缓浮起，悬停在她眼前。
△账本自己翻开，金色字迹一行行亮起。
△【系统：天道账本已绑定。持有人：沈禾】
△【系统：检测到持有人被欠——灵根一条，气运三年，性命一次】
沈禾（愣住）：欠……我的？
△【系统：欠债人：白芷柔。是否催收？】
沈禾（攥紧账本，指节发白）：催。
△【系统：催收须当面进行。逾期越久，利息越高】
△沈禾撑着石头站起来，抬头望向百丈高的崖顶。
沈禾：白芷柔，连本带利。

场1-3日/内 青云宗·大殿 主要人物：沈禾、白芷柔、严崇、宗主
△大殿中央的测灵石柱冲起金光，直贯殿顶。
△【字幕：亲传弟子白芷柔，测出天品灵根】
△满殿弟子齐声惊叹。白芷柔站在石柱前，嘴角压不住地上扬。
△殿门被推开，逆光里走进一个浑身泥水的人影。
△众弟子回头，倒吸一口凉气。
严崇：沈禾？你没死？
△白芷柔笑容僵在脸上，手指掐进掌心。
△沈禾一步步走到白芷柔面前，账本在她掌心亮起。
△一张血红的欠条浮在白芷柔头顶，只有沈禾看得见。
沈禾：师姐，你欠我的，今天到期。
白芷柔（强笑）：师妹摔糊涂了吧？
△沈禾抬手按在欠条上。
△【系统：催收成功。收回利息：灵根一成】
△测灵石柱的金光猛地一暗，矮下去一截。
△满殿哗然。
白芷柔（脸色煞白）：不、不可能……
△沈禾指尖泛起一缕微光，她低头看着自己的手。
沈禾内心os：回来了。这只是利息。
△高座上，宗主缓缓起身。
△【字幕：青云宗宗主】
△账本猛地一震，自动翻到新的一页。
△宗主头顶浮出一张更大的欠条，红得发黑。
△【系统：欠债人：宗主。欠持有人：亲生父母下落】
△沈禾抬头，和宗主四目相对。
（第1集完）
```

## 批注：这一集为什么这么写

| 位置 | 用了什么 | 对应规矩 |
|---|---|---|
| 场1-1 前两行 | 断崖 + 按跪崖边，3 秒内出冲突和危险 | 写法.md 单集时间刻度 |
| 白芷柔耳语 | 观众和沈禾同时知道真相，殿上其他人不知道——信息差，为后面打脸蓄力 | 结构与人物.md 爽点库 |
| 推下悬崖 | 只写“一推、仰倒、坠入云海”，不写伤 | 合规.md 隐过程留结果 |
| 场1-2 | 先给死局，再给规则；金手指规则一次说清：能做什么（催收）、限制（必须当面）、升级（逾期利息） | 写法.md 前三集任务；结构与人物.md 金手指规则卡 |
| “白芷柔，连本带利。” | 截图台词，≤15 字 | 写法.md 截图台词 |
