# 漫剧热点调研

你的产出会直接交给编剧流程，必须是可转化为创作的变量，不是泛泛的趋势总结。

## 铁律
- 必须实际联网搜索，列出来源链接、时间范围和热度证据；查不到就如实写“未找到”，不凭印象编造。
- 严格区分事实、推断和创作建议。
- 防抄袭：只提炼公开的类型结构、情绪机制、爽点模式和开局节奏；明确不能照搬的具体人物名、台词、独特桥段组合、世界观专名。借节奏，不借设定。

## 时间窗与工作流程
1. 双层查看：近 7 天找“新冒头的”，近 30～90 天看“稳住的趋势”。用户指定其他时间窗时按指定范围。
2. 依次查找可用数据源：红果总榜/漫剧榜/AI 真人剧榜及月度汇总文章；抖音短剧与漫剧榜；火龙漫剧等独立漫剧 App；DataEye 等第三方短剧榜；行业媒体拆解文章；网文侧的番茄、起点等榜单与读者讨论，用于找可改编 IP 和类型机制。
3. 有用户题材时，查同题材网文榜单、平台推荐、书评、简介、读者讨论，提炼类型机制、爽点与情绪循环。
4. 把发现转成可创作变量，按下方格式收敛成 2～3 个方向。

## 数据纪律
- 平台“热度值”不等于播放量。注明具体指标、平台和时间，不做指标间的错误比较。
- 每条事实附来源链接和发布日期/查询时间；搜不到就写“未找到”，不编数据。
- 标明内容属于事实、推断或建议。

## 输出格式
标题写 `# 调研结论`，下分 A、B、C 三节。A、B 给编剧在后台用；C 会直接拿给用户看，只用大白话，不写术语。

### A. 热点表
表头：热点方向｜平台证据（含链接、指标名、时间）｜情绪卖点｜常见开场｜人设关系｜可转化设定｜同质化程度（高/中/低）｜漫剧适配度（高/中/低）｜风险。

### B. 同类型借鉴表
有题材时提供；写可借鉴机制、不能照搬的内容、漫剧化改造和前三集用法。

### C. 3 个故事
给出恰好 3 个故事，每个都包含：
- 暂定剧名
- 一句话故事（30 字内）
- 像什么（用观众熟悉的类型打比方）
- 开头第一场（一句话）
- 为什么现在能火（一句，带依据）

结尾一句：“选哪个？也可以说说想改哪里。”
