什么时候读本文件：写剧本、设计前三集、估算单集时长或检查格式与留存节奏时读本文件。

# 写法

## 前三集任务
| 集数 | 任务 |
|---|---|
| 第一集 | 前五秒强视觉冲击；主角或至亲的生命/尊严至少失去一个；觉醒能力；用能力完成第一次小反击；结尾给更大的危机、真相、敌人或关系反转。第一集不解释世界观，先把主角扔进具体绝境，让世界观从绝境和规则里露出来。金手指在绝境再升级一次之后出现：先给死局，再给规则。 |
| 第二集 | 出现伴侣/盟友和前期主要敌人；展示能力范围、限制与代价；结尾给威胁主角、至亲、盟友或关键保护对象的危机。 |
| 第三集 | 兑现第二集危机；主角和敌人正面交手；给第一次大爽点；情感高潮落在人身上，让观众想看主角赢。 |

卖点里的核心情绪事件（相认、重逢、觉醒、身份揭开、下山寻亲）必须在前三集**演出来**，不能当成开场前已经发生。观众点开就是冲着这场戏来的。

第一集第一行必须是“动作 + 危险或反差”的画面（有人在做什么、出了什么事），不能是静态陈列或一串字幕。人物字幕跟着该人物第一次动作或开口出现，一次最多一条。

## 单集时间刻度
- 0～3 秒：冲突或奇观。
- 10 秒内：主角立场清楚。
- 中段：至少一次反转或信息增量。
- 最后 5 秒：断在最大悬念。

每集必须同时有三标：钩子、信息增量、悬念，缺一样不交。

## 集尾钩子六类
| 类型 | 是什么 | 原创短例 |
|---|---|---|
| 身份悬念 | 新身份即将揭开 | △门外的人摘下旧徽章，守卫齐齐低头。 |
| 危机降临 | 新危险进入眼前 | △城墙上的警铃骤响，火光映红天边。 |
| 真相半露 | 证据只揭开一角 | △旧信背面浮出第二个收件人的名字。 |
| 反转打脸前一秒 | 结果即将推翻当前判断 | △验灵石亮起，主持人刚要宣布结果。 |
| 关系突变 | 重要关系突然改变 | 叶澄：从现在起，你别再叫我师姐。 |
| 更大的对手登场 | 出现更高层级的阻力 | △远处高台亮起，新的掌印压住全场。 |

## 集尾禁忌
- 不用总结式结尾或“欲知后事”。
- 钩子必须在下一集兑现，不能只抛不接。
- 钩子要能被观众用一个问句问出来（“信里写了谁？”“他会不会当场认出她？”）。只交代现状（“协议那栏还空着”）或重复上一集已有的威胁，都不算钩子。
- 相邻两集的钩子不能是同一个威胁的重复；同一个威胁要升级（来的人更多、赌注更大、期限更近）才算新钩子。


## 唯一剧本格式
所有剧本和剧本片段只使用以下格式：

```text
第1集
场1-1日/外 青云宗·断崖 主要人物：沈禾、白芷柔、严崇
△断崖边狂风大作，碎石滚进深渊。
△【字幕：沈禾，青云宗杂役弟子】
严崇（举起碎玉）：偷盗圣物，按律逐出山门。
沈禾：不是我！
沈禾内心os：是她放进我包袱的。
旁白：三年前，沈禾也是宗门第一天才。
【闪回】
场1-2夜/内 沈禾旧居 主要人物：沈禾（少年）、白芷柔
△……
【闪回结束】
△【系统：天道账本已绑定】
（第1集完）
```

格式规则：
- 场序：`场集数-场次日/内 地点 主要人物：A、B`。日/夜 + 内/外；地点可用“·”分大小地点。
- 对白以外的一切（动作、表情、场景、字幕、系统面板、道具文字、转场）行首加 `△`；字幕和系统面板也加 `△`。
- 对白：`人物名：台词`；动作情绪放括号 `人物名（冷笑）：台词`。
- 内心：`人物名内心os：`。画外音：`人物名（画外音）：`。旁白：`旁白：`。
- 闪回：单独一行 `【闪回】`，闪回里另起场序，结束单独一行 `【闪回结束】`。
- 人物首次出场：`△【字幕：姓名，身份】`。
- 形态/年龄/服装变化：在“主要人物”里括号标注，如 `沈禾（觉醒形态）`、`林野（17岁）`。
- 集标题和场序一律用阿拉伯数字：`第5集`、`场5-1`，不写`第五集`。
- 集末：`（第X集完）`。
- 禁止 `▲`、`（OS）`、不带“内心”的 `OS：`、`【闪回开始】`、`1-1 地点 日 内` 式旧场序。
- 对白行里的动作只能放括号：写 `苏青（扶住他）：台词`，不写 `苏青扶住他：台词`。

## 时长估算
总时长 = 有声文本时长（台词、旁白、内心os、系统面板朗读，每分钟 200～250 字）+ 无台词动作时长（每处独立的无台词动作行约 2～3 秒）。整集含动作行约每分钟 400～500 字，只作粗参考。交稿时集末另起一行注：

`【本集有声文本约 X 字≈X 秒；无台词动作约 X 处≈X 秒；预估总时长约 X 分 X 秒】`

预估总时长低于目标下限（默认 1.5 分钟）的不交稿：补一段“主角受压”或“主角回击”的戏，或让已有冲突多打一个回合（对手还一招、主角再压回去）。不靠加旁白、加空镜凑时长。

## AI 可生成写法
| 做 | 不做 |
|---|---|
| 一行一个主体、一个动作 | 一行塞三个人四个动作 |
| 打戏写结果 + 一个标志动作（剑光掠过，三名黑衣人同时倒地） | 一招一式连续格斗 |
| 写可见生理反应（瞳孔一缩、攥紧拳、后退半步） | 写“心中五味杂陈” |
| 群演写“众弟子哗然”，最多给一句台词 | 群演各有台词 |
| 画面中的信、屏幕、面板写全文且 ≤20 字 | 写“信上写满了真相” |
| 尽量复用剧本圣经“场景库”里的场景 | 每集新地点 |
| 精细手部操作尽量写结果 | 长时间特写穿针、拆线等手部动作 |
| 形态和服装变化标在“主要人物”里 | 不标注就换装 |
| 奇观说清是什么、多大、什么颜色 | 写“出现了很厉害的东西” |
| 把心理变成动作、表情、台词或内心os | 直接写抽象心理状态 |

漫剧长处是视觉奇观，每集至少一个截图画面，如变身、法相、巨兽、天象、系统面板或反差造型。
旁白有声文本占比 ≤30%（解说漫除外），只交代画面看不出的信息，不复述画面。
每集至少一句可单独截作宣传素材的狠话或金句（≤15 字）。弱——“那我更得去。”（只表态，没态度）；强——“这城里的垃圾，归我收。”（身份反差 + 狠劲 + 可单独截出）。
