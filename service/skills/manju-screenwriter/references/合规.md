## 合规≠不狠
改掉红线后，必须用合法手段把狠劲补回来：当众揭穿、证据砸脸、身份反转、让反派失去最在乎的东西（面子、地位、钱、人心）。台词可以狠，手段必须合法。用户要“越狠越好”时，狠在情绪和反击力度，不在伤害过程。

## 红线
| 类别 | 不能写 | 可以怎么写 |
|---|---|---|
| 重点类题材 | 不慎重处理 | 尽量不碰；必须碰时提醒用户走重点类审核 |
| 血腥暴力 | 伤害过程和伤口细节 | 写结果和反应 |
| 死亡 | 遗体细节 | 用人物反应或事件结果表达 |
| 自杀自残 | 方法、过程，或写成解脱/报复手段 | 剧情需要时只写“被及时救下/事后被告知”，并给求助出口 |
| 色情擦边 | 身体特写、打擦边的剧名和台词 | 亲密到牵手、拥抱、额头相抵为止 |
| 违法犯罪 | 可模仿的手法、美化犯罪 | 交代结果与追责，不展示操作 |
| 封建迷信 | 现实中可照做的算命、招魂、符咒“灵验” | 玄幻世界里的法术可以写 |
| 未成年人 | 恋爱、受虐、危险可模仿行为、被当坏人工具 | 写大人保护或孩子用智慧化解危机 |
| 价值导向 | 私刑折磨；渲染拜金、出轨、欺凌为爽；污名化群体 | 复仇止于讨回公道和法律惩处；伦理冲突落在具体的事 |
| 肖像与版权 | 真实人物、真实品牌、他人 IP 的人名设定 | 使用原创人物、设定和名称 |
| 吸烟酗酒 | 美化吸烟或酗酒 | 尽量不写，必须写就不美化 |

## 隐过程、留结果
不描写具体伤害操作，保留可见结果、人物反应和剧情后果。以下片段均用统一剧本格式：

```text
第1集
场1-1日/外 旧桥 主要人物：许棠、顾原
△一阵尘土扬起，顾原手里的木剑落在地上。
许棠：到此为止。
（第1集完）
```

```text
第1集
场1-1夜/内 书房 主要人物：林澈、管家
△管家将一只合上的药盒放到桌边，林澈没有伸手。
林澈：请大夫来。
（第1集完）
```

```text

场1-1日/外 林间空地 主要人物：周遥、沈砚

沈砚：人已经被带走了。
（第1集完）
```
