什么时候读本文件：改编小说、改别人的剧本或根据审读意见返修时读本文件。

# 改编与改稿


## 开工前
问一次是否有改编授权。用户未说明，就在立项包“合规备注”写“需确认已获改编授权”，不阻塞工作。

## 改编五步
1. **拆原著，交三张表。**主线骨架（按卷/大地图，每卷一句）；爽点清单（章节号｜爽点类型｜强度 1～5）；人物表（功能、首次出场章节、能否合并）。原著很长时分卷处理。
2. **定集章比。**前期 1 集约原著 1～2 章，中后期 1 集约 3～5 章；按“每集一件事、每集一兑现”反推，不按字数切。
3. **删、并、提、外化。**删支线和功能重复的配角；合并同功能人物；把原著最强的早期爽点提前到第 1～3 集；把内心描写外化为动作、台词、内心os或系统面板。
4. **漫剧化。**世界观用“绝境 + 规则”释放，不用大段旁白讲设定；每集找一个原著里的奇观画面，放大成截图画面。
5. **切季。**按原著卷或地图切季，每季末尾找原著里的“新地图/新身份”节点做季终钩子。

改编后照样走拍板 2、拍板 3，再自动写完。

## 改编不改的东西
保留原著核心人设、核心关系、读者最爱的名场面，并在漫剧结构中保留、放大。

## 常见病与药方
| 问题 | 改法 |
|---|---|
| 写成小说、堆心理描写 | 外化成动作、表情、台词或内心os |
| 爽点埋着不给 | 当集兑现一部分 |
| 反派降智 | 给反派合理动机和一招狠棋 |
| 集尾是总结 | 改成新问题 |
| 台词又长又解释 | 拆短、删解释、留潜台词 |
| 场景太多 | 合并到一个地点 |
| 憋屈太久 | 中段插一次小回击 |
| 金手指没代价 | 补代价 |
| 同类爽点连用 | 换爽点类型 |
| 群演抢戏 | 收成一句 |
| 旁白复述画面 | 删掉复述 |
| 钩子下集不兑现 | 下集开头 10 秒内兑现 |

## 改稿流程
先通读并给诊断（≤10 条，按严重程度排序），再跟用户确认改到什么程度：只修格式、修节奏或大改结构；确认后动手，最后给“改了什么”清单。保留原作者的长处，不为改而改。

改后剧本和新写的剧本标准一样：集尾钩子按 references/写法.md 的规则（能被观众用一个问句问出来），时长不低于 references/写法.md 的下限，格式按 references/写法.md。

审读报告按「漫剧剧本审读」助手的输出要求整理。
