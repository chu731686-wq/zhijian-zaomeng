## T-013 登录注册

- `/login`：用户名/邮箱密码登录；邮箱验证码分步注册；忘记密码与重设后自动登录；Google 首次登录补邀请码；隐藏 Linux.do 按钮并保留原代码。
- `/admin/invites`：生成、复制、查看使用账号/时间、作废一次性邀请码。
- 验证码仅存哈希，10 分钟过期、60 秒冷却、五次错误作废；邮箱/IP 持久化限流；自动迁移旧库。
- 配置真实 SMTP 与 Google OAuth 后联调邮件投递、Google 同意/取消/首次邀请/后续登录；本机无 SMTP 验证流程见 [认证配置与验收](../backend/authentication.md)。

自动验证已通过任务卡的 `go build ./...` 与 TypeScript 检查；离线进程内请求覆盖无 SMTP 注册/忘记密码/自动登录、旧库迁移、邀请码回滚/作废/单次消费、验证码冷却/五错/过期，以及模拟 Google HTTP 回调。沙箱不允许监听本机端口，真实浏览器、SMTP 和 Google 授权需在配置后的运行环境验收。
